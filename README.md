A high-fidelity React prototype for a tattoo studio service website developed using User-Centered Design (UCD) principles.

## Live Demo

https://sai-yarla.github.io/SEG3125-Assignment-2/

## Features

* Browse tattoo artists and portfolios
* View artist profiles and specialties
* FAQ section for first-time clients
* Consultation booking system
* Appointment scheduling calendar
* Session booking workflow
* Deposit and confirmation process
* Responsive design for desktop and mobile devices

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

```bash
git clone https://github.com/Sai-Yarla/SEG3125-Assignment-2.git
cd SEG3125-Assignment-2
npm install
```

### Run Locally

```bash
npm start
```

### Build for Production

```bash
npm run build
```

## Project Goal

Ink & Ease Studio was designed to provide an intuitive booking experience for both first-time and returning tattoo clients. The interface combines artist discovery, educational content, and streamlined appointment scheduling within a cohesive user experience.
